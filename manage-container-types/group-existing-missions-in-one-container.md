# Bestaande missies in één container groeperen

1. Selecteer de missie(s) die bedoeld zijn om te groeperen.

<figure><img src="../.gitbook/assets/image (595).png" alt=""><figcaption></figcaption></figure>

2. Klik op het menu Acties.
3. Selecteer Groeperen in één container.

<figure><img src="../.gitbook/assets/image (596).png" alt=""><figcaption></figcaption></figure>

4. Klik op Toepassen om de bovenliggende ID voor de geselecteerde missies bij te werken.
5. Kies een nieuwe container om een nieuwe bovenliggende container te maken, of selecteer een bestaande container op basis van zijn ID.

<figure><img src="../.gitbook/assets/image (597).png" alt=""><figcaption></figcaption></figure>

De missies zijn gegroepeerd in de bovenliggende missie

<figure><img src="../.gitbook/assets/image (599).png" alt=""><figcaption></figcaption></figure>

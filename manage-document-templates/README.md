# Documentsjablonen beheren

**Sjablonen beheren voor Missie-documenten**

Met de functie Documentsjablonen beheren kunnen beheerders en backofficegebruikers herbruikbare sjablonen maken, configureren en onderhouden voor documenten zoals leveringsbonnen, facturen, bewijs van levering en taakrapporten. Deze sjablonen standaardiseren de documentatie binnen de werkzaamheden en zorgen voor consistentie in branding, structuur en vereiste informatie.

U kunt uw eigen sjablonen ontwerpen ter vervanging van het standaard sjabloon.

| Sjablonen                | Gekoppelde variabelen                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Routelijst               | Missie, Route                                                                                                 |
| Laadlijst                | Missie, Route                                                                                                 |
| Missieblad               | missie                                                                                                        |
| Stickerblad              | missie                                                                                                        |
| Vrachtbrieven            | Missie, Agentschap, Aannemer, Bedrijf, Voertuig, Bezorger, Aangepaste gegevens, Documenten, Statuswijzigingen |
| Bezoekrapport            | Missie Open Order                                                                                             |
| Blad met kleine stickers | missie                                                                                                        |

#### Een documentsjabloon downloaden

1. Ga naar Configuratie.
2. Klik op het configuratiemenu
3. Klik onder Aanpassingen op Documentsjablonen
4. Selecteer het gewenste document uit de lijst

<figure><img src="../.gitbook/assets/image (655).png" alt=""><figcaption></figcaption></figure>

5. Klik op het vervolgkeuzemenu Acties
6. Klik op Downloaden

<figure><img src="../.gitbook/assets/image (656).png" alt=""><figcaption></figcaption></figure>

De documentsjablonen worden succesvol gedownload.

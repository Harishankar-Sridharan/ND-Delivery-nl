# Onderaannemersbeheer

De functie voor het beheer van onderaannemers stelt vervoerders in staat logistieke taken te delegeren aan onderaannemers, waardoor samenwerkingen vlotter verlopen en de operationele flexibiliteit toeneemt.

Deze functie zorgt ervoor dat onderaannemers efficiënt worden beheerd, zodat logistieke operaties geoptimaliseerd blijven en afgestemd zijn op de bedrijfsdoelstellingen.

In de Nomadia Delivery-applicatie moeten onderaannemers door de vervoerder worden geregistreerd voordat ze missiedata kunnen uploaden. Om dit te doen, moet de vervoerder de onderaannemer toevoegen via de module Onderaannemer.

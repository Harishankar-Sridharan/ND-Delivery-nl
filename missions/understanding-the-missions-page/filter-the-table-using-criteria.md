# De tabel filteren met criteria

| Gegevenstype     | Operator     |
| ---------------- | ------------ |
| **Alfanumeriek** | =            |
|                  | ≠            |
|                  | Bevat        |
|                  | Bevat niet   |
|                  | Begint met   |
|                  | Eindigt op   |
|                  | Is leeg      |
|                  | Is niet leeg |
| **Datum**        | =            |
|                  | =D+          |
|                  | =D-          |
|                  | ≤D+          |
|                  | ≤D-          |
|                  | ≥ D+         |
|                  | ≥ D-         |
|                  | <            |
|                  | ≤            |
|                  | >            |
|                  | ≥            |
|                  | ≠            |
|                  | Is leeg      |
|                  | Is niet leeg |
| **Rekenkundig**  | =            |
|                  | ≠            |
|                  | <            |
|                  | ≤            |
|                  | >            |
|                  | ≥            |

1. Klik op de **Filterinvoerveld.**
2. Selecteer de juiste voorwaarde uit de suggesties.
3. Kies de relevante operator uit de vervolgkeuzelijst.
4. Voer de vereiste waarde voor de voorwaarde in.
5. Druk op de **Enter** toets om het filter toe te passen.

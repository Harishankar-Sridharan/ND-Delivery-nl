# Een gebruiker aanmaken vanuit een bestaande gebruiker

1. Klik in Gebruikers beheren op de **keuzelijst Acties** en selecteer **Toevoegen**.
2. Stel 'Aanmaken op basis van bestaande gebruiker' in op **Ja**.
3. Selecteer de bestaande gebruiker uit de lijst.
4. Kiezen **Ja** of **Nee** voor het importeren van de voorkeuren van de gebruiker, indien nodig.
5. Klik op **OK**

<figure><img src="../.gitbook/assets/image (150).png" alt=""><figcaption></figcaption></figure>

6. Wijzig de gebruikersgegevens indien nodig.

<figure><img src="../.gitbook/assets/image (151).png" alt=""><figcaption></figcaption></figure>

7. Klik op **Opslaan** om het proces te voltooien.

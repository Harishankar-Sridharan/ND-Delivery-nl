# Mobiel - Rollen en rechten

| <p><br>Rollen en rechten</p>           | Beschrijving                                                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Levering                               | Wanneer ingeschakeld, kunnen gebruikers leveringsgerelateerde handelingen uitvoeren.                           |
| Aanmeren                               | Wanneer ingeschakeld, kunnen gebruikers aanmeeractiviteiten openen en beheren.                                 |
| Laden / Lossen                         | Wanneer ingeschakeld, kunnen gebruikers pakketten in hun voertuigen laden en lossen.                           |
| Laden wanneer niet volledig voorbereid | Wanneer ingeschakeld, kunnen gebruikers pakketten laden, zelfs als de missie niet volledig is voorbereid.      |
| Voorbereiden                           | Wanneer ingeschakeld, kunnen gebruikers missies voorbereiden vóór uitvoering.                                  |
| Ontvangst                              | Wanneer ingeschakeld, kunnen gebruikers pakketten ontvangen op de bestemming of in het depot.                  |
| Opslag                                 | Wanneer ingeschakeld, kunnen gebruikers pakketten naar opslaglocaties verplaatsen.                             |
| Onbekende missies scannen              | Wanneer ingeschakeld, kunnen gebruikers missies die niet vooraf zijn gedefinieerd scannen en verwerken.        |
| Routes aanmaken                        | Wanneer ingeschakeld, kunnen gebruikers leveringsroutes aanmaken en beheren.                                   |
| Niet-toegewezen leveringen afhandelen  | Wanneer ingeschakeld, kunnen gebruikers leveringen beheren die niet aan een route of resource zijn toegewezen. |
| Niet-toegewezen ophalingen afhandelen  | Wanneer ingeschakeld, kunnen gebruikers ophalingen beheren die niet aan een route of resource zijn toegewezen. |
| Missies opnieuw toewijzen              | Wanneer ingeschakeld, kunnen gebruikers missies opnieuw toewijzen aan andere routes of resources.              |
| Scannen niet verplicht                 | Wanneer ingeschakeld, is het scannen van pakketten optioneel tijdens handelingen.                              |
| Adressen herpositioneren               | Wanneer ingeschakeld, kunnen gebruikers missie-adressen wijzigen of corrigeren.                                |
| Supervisor-scherm                      | Wanneer ingeschakeld, kunnen gebruikers het monitoringscherm van de supervisor openen.                         |
| Pakketoverdracht                       | Wanneer ingeschakeld, kunnen gebruikers pakketten overdragen tussen missies of containers.                     |
| Groeperen in een container             | Wanneer ingeschakeld, kunnen gebruikers meerdere pakketten groeperen in één container.                         |
| Missies wijzigen                       | Wanneer ingeschakeld, kunnen gebruikers missiedetails bewerken.                                                |
| Maak het gesprek verplicht             | Wanneer ingeschakeld, moeten gebruikers een telefoontje plegen voordat de missie wordt voltooid.               |

#### Wachtwoordbeleid voor mobiele toegang

Het wachtwoord moet minimaal 8 tekens bevatten, waaronder ten minste één hoofdletter, één kleine letter en één cijfer

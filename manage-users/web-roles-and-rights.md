# Web - Rollen en rechten

| Rollen en rechten                              | Beschrijving                                                                                                 |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Beheer**                                     | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot administratieve configuratiefuncties.            |
| Artikelen beheren                              | Wanneer ingeschakeld, kunnen gebruikers artikelen aanmaken, bijwerken en beheren.                            |
| **Missies**                                    | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot missiegerelateerde functionaliteiten.            |
| Lijst van missies                              | Wanneer ingeschakeld, kunnen gebruikers de lijst met alle missies bekijken.                                  |
| Missies aanmaken                               | Wanneer ingeschakeld, kunnen gebruikers nieuwe missies aanmaken.                                             |
| Vrij adres beschikbaar                         | Wanneer ingeschakeld, kunnen gebruikers missies aanmaken zonder een vooraf gedefinieerd adres te selecteren. |
| Missies importeren                             | Wanneer ingeschakeld, kunnen gebruikers missies in bulk importeren.                                          |
| Missies verwijderen                            | Wanneer ingeschakeld, kunnen gebruikers bestaande missies verwijderen.                                       |
| Missies wijzigen                               | Wanneer ingeschakeld, kunnen gebruikers missiedetails bewerken.                                              |
| Missies wijzigen na afdrukken                  | Wanneer ingeschakeld, kunnen gebruikers missies wijzigen, zelfs nadat ze zijn afgedrukt.                     |
| De route volgen                                | Wanneer ingeschakeld, kunnen gebruikers routedetails en voortgang bekijken.                                  |
| De route beheren                               | Wanneer ingeschakeld, kunnen gebruikers routes aanmaken, bewerken en beheren.                                |
| Weergaveparameters aanpassen                   | Wanneer ingeschakeld, kunnen gebruikers de weergave-instellingen van missies aanpassen.                      |
| **Tickets**                                    | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot ticketbeheerfuncties.                            |
| De lijst met tickets bekijken                  | Wanneer ingeschakeld, kunnen gebruikers de lijst met tickets bekijken.                                       |
| Reageren op tickets                            | Wanneer ingeschakeld, kunnen gebruikers op tickets reageren.                                                 |
| **Optimalisatie**                              | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot optimalisatiefuncties.                           |
| Planning                                       | Wanneer ingeschakeld, kunnen gebruikers geoptimaliseerde planningen aanmaken en beheren.                     |
| Simulaties van anderen bekijken                | Wanneer ingeschakeld, kunnen gebruikers simulaties bekijken die door andere gebruikers zijn gemaakt.         |
| Simulaties van anderen bewerken                | Wanneer ingeschakeld, kunnen gebruikers simulaties wijzigen die door andere gebruikers zijn gemaakt.         |
| Optimalisatie-instellingen wijzigen            | Wanneer ingeschakeld, kunnen gebruikers optimalisatieparameters configureren.                                |
| **Depot**                                      | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot depotgerelateerde functies.                      |
| De depots beheren                              | Wanneer ingeschakeld, kunnen gebruikers depots aanmaken, bijwerken en beheren.                               |
| **Voertuigen**                                 | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot voertuigbeheersfuncties.                         |
| De voertuigen beheren                          | Wanneer ingeschakeld, kunnen gebruikers voertuigen aanmaken, bijwerken en beheren.                           |
| De weergave van vloten en voertuigen aanpassen | Wanneer ingeschakeld, kunnen gebruikers vloot- en voertuigbeperkingen aanpassen.                             |
| **Afhandeling**                                | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot afhandelingsfuncties.                            |
| Afhandelingsopvolging                          | Wanneer ingeschakeld, kunnen gebruikers de voortgang en status van de afhandeling volgen.                    |
| Planning van anderen bekijken                  | Wanneer ingeschakeld, kunnen gebruikers planningen bekijken die door andere gebruikers zijn gemaakt.         |
| **Opdrachtnemers**                             | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot functies voor contractormanagement.              |
| Lijst van contractanten                        | Wanneer ingeschakeld, kunnen gebruikers de lijst met contractanten bekijken.                                 |
| Contractanten aanmaken                         | Wanneer ingeschakeld, kunnen gebruikers nieuwe contractanten aanmaken.                                       |
| Contractanten importeren                       | Wanneer ingeschakeld, kunnen gebruikers contractanten in bulk importeren.                                    |
| Contractanten verwijderen                      | Wanneer ingeschakeld, kunnen gebruikers contractanten verwijderen.                                           |
| Contractanten wijzigen                         | Wanneer ingeschakeld, kunnen gebruikers contractantgegevens bewerken.                                        |
| **Adreslijst**                                 | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot adresbeheerfuncties.                             |
| Adreslijst (weergave)                          | Wanneer ingeschakeld, kunnen gebruikers de lijst met adressen bekijken.                                      |
| Adressen aanmaken                              | Wanneer ingeschakeld, kunnen gebruikers nieuwe adressen aanmaken.                                            |
| Adressen importeren                            | Wanneer ingeschakeld, kunnen gebruikers adressen in bulk importeren.                                         |
| Adressen verwijderen                           | Wanneer ingeschakeld, kunnen gebruikers adressen verwijderen.                                                |
| Adressen wijzigen                              | Wanneer ingeschakeld, kunnen gebruikers adresgegevens bewerken.                                              |
| **Onderaannemers**                             | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot functies voor onderaannemersbeheer.              |
| Lijst van onderaannemers                       | Wanneer ingeschakeld, kunnen gebruikers de lijst met onderaannemers bekijken.                                |
| Onderaannemers aanmaken                        | Wanneer ingeschakeld, kunnen gebruikers nieuwe onderaannemers aanmaken.                                      |
| Onderaannemers bijwerken                       | Wanneer ingeschakeld, kunnen gebruikers de gegevens van onderaannemers bijwerken.                            |
| Onderaannemers verwijderen                     | Wanneer ingeschakeld, kunnen gebruikers onderaannemers verwijderen.                                          |
| Onderaannemers importeren                      | Wanneer ingeschakeld, kunnen gebruikers onderaannemers in bulk importeren.                                   |
| Lijst van het schema van de onderaannemer      | Wanneer ingeschakeld, kunnen gebruikers de planningen van onderaannemers bekijken.                           |
| Lijst van voertuigen van onderaannemers        | Wanneer ingeschakeld, kunnen gebruikers de voertuigen van onderaannemers bekijken.                           |
| **Dashboard en KPI's**                         | Wanneer ingeschakeld, kunnen gebruikers toegang krijgen tot dashboards en KPI's.                             |
| Dashboards bekijken                            | Wanneer ingeschakeld, kunnen gebruikers dashboards en KPI-gegevens bekijken.                                 |
| Dashboards wijzigen                            | Wanneer ingeschakeld, kunnen gebruikers dashboards aanmaken en wijzigen.                                     |

#### Wachtwoordbeleid voor webtoegang

Het wachtwoord moet ten minste drie van de volgende teken પ્રકારen bevatten:

* Kleine letters (a–z)
* Hoofdletters (A–Z)
* Cijfers (0–9)
* Symbolen (speciale tekens)
